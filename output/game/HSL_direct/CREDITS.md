# Horror Signal Lost - credits

A single-room horror micro-game. Everything here is either original code and
writing, procedurally generated (noise textures and audio beds), or CC0
art/audio from the workspace library.

## Engine

- Godot Engine 4.6.2 (MIT).

## Fonts (CC0)

- `assets/fonts/KenneyFutureNarrow.ttf`, `KenneyFuture.ttf`,
  `KenneyMiniSquare.ttf`, `KenneyMiniSquareMono.ttf`
  - Kenney Fonts, Kenney Vleugels (kenney.nl). CC0.

## Writing, design and code

Original work created for this game. The station, the signals, the operator
and everything that answers them are fiction.

## A note on the horror

The entity in this game is a metaphor for a signal that never stops
transmitting. It is not real. The static on your radio is probably just
static.
